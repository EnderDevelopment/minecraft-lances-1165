# Minecraft Forge Mod: LanceMod_1.16.5

LanceMod_1.16.5 is a Minecraft Forge mod for Minecraft 1.16.5 that adds five material spears with passive potion effects, crafting recipes, item models, durability, and a forward dash activated by swinging the spear.

## Install

1. Install Minecraft Forge 36.2.39 for Minecraft 1.16.5.
2. Build the project with Java 8:
   - Linux or macOS: `./gradlew build`
   - Windows: `gradlew.bat build`
3. Find the generated mod jar in the `build/libs` folder.
4. Copy the jar to the Minecraft `mods` folder.
5. Start Minecraft using the Forge 1.16.5 profile.

## Use

1. Craft a spear using the material recipe:
   - Wooden Spear: oak planks and a stick
   - Stone Spear: cobblestone and a stick
   - Iron Spear: iron ingots and a stick
   - Diamond Spear: diamonds and a stick
2. Upgrade a Diamond Spear to a Netherite Spear in a smithing table with a netherite ingot.
3. Hold a spear in either hand to receive its passive effect.
4. Swing the spear with the attack button to dash forward.
5. Wait one second before using the dash again.

Spear effects:

- Wooden Spear: Weakness
- Stone Spear: Speed
- Iron Spear: Resistance
- Diamond Spear: Strength
- Netherite Spear: Weakness, Speed, Resistance, and Strength at level 4

All spears have a stack size of one and 250 durability.
